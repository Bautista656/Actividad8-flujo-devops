# Actividad8-flujo-devops
Proyecto para definir flujo de trabajo, versionamiento y despliegue CI/CD

## Flujo de trabajo

Este proyecto utiliza un flujo basado en ramas principales y ramas de trabajo.

- main: rama estable del proyecto.
- develop: rama de integración para juntar cambios antes de pasarlos a main.
- feature/*: ramas creadas para desarrollar nuevas funciones o documentación.

Los cambios se integran mediante Pull Requests para permitir revisión antes de hacer merge.
